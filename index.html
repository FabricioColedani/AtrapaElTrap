¿Cómo se juega?

  1. Aparece una tarjeta de segmento con su Base y su Límite.
  2. Tienes 3 segundos para decidir si el acceso es Válido o un TRAP.
  3. Es válido si el desplazamiento está entre 0 y Límite−1. Dirección física = Base + desplazamiento.
  4. Aciertos suman, la velocidad da bono y 3 seguidos activan combos (x2, x3, x4).

Teclado: ← o V = Válido · → o T = TRAP
